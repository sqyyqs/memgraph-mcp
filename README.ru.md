# memgraph-mcp

[English version](README.md)

Разрабатывается открытый MCP-сервер общей графовой памяти для нескольких LLM-агентов на базе Neo4j. 
Система поддерживает запись фактов с provenance (агент, источник, время события и время записи), 
темпоральные запросы «состояние на момент t», извлечение релевантного подграфа с ограничением по токен-бюджету 
и обнаружение конфликтов при добавлении новых фактов.

Исследовательский вопрос: позволяет ли общая графовая память с provenance, 
темпоральностью и бюджетным извлечением контекста сохранить качество ответов 
при снижении объёма передаваемого контекста и приемлемой задержке по сравнению с существующими решениями.

Данные: бенчмарк диалоговой памяти LoCoMo. Предлагаемая система сравнивается с Graphiti-MCP, Mem0 и full-context на одной открытой LLM.

Обязательный результат: протестированный MCP-сервер с документированным API и воспроизводимым экспериментом.
Метрики сравнения — качество ответов по LLM-judge, число токенов на запрос, p95 latency и precision обнаружения конфликтов. 
Критерий успеха: качество не ниже Graphiti-MCP более чем на 2 п.п.,
использование не более 70 % токенов на запрос и precision конфликтов не ниже 0,8.

Желаемый результат: расширение сравнения до Mem0^g и dense RAG, 
проведение экспериментов на трёх сидах с доверительными интервалами и ablation-анализ влияния темпоральности, способа извлечения, размера токен-бюджета и используемой модели.

Артефакты проекта: открытый репозиторий с воспроизводимым запуском экспериментов, 
контракт MCP-интерфейса для агентов и технологический отчёт.

## Быстрый старт

```bash
cp .env.example .env          # заполните ключи; .env не попадает в репозиторий
uv sync                       # ставит пакет и инструменты разработки из uv.lock
uvx pre-commit install        # gitleaks, большие файлы, make check перед каждым коммитом
make check                    # ruff, mypy, pytest
make run                      # один эксперимент: configs/smoke.yaml -> запуск в MLflow
make mlflow                   # интерфейс MLflow над локальной базой mlflow.db
```

Один раз переименуйте пакет: `make rename NAME=<имя_пакета>`, затем `uv lock`.

## Структура

```
src/<пакет>/         код, который импортируется и тестируется: config.py, pipeline.py, __main__.py
tests/               smoke-тест: пайплайн на крошечном входе
configs/             конфиги экспериментов (YAML)
notebooks/           исследовательский анализ; вывод ячеек можно оставить как отчёт о результате
docs/adr/            журнал решений, один файл на решение
docs/meetings/       записи встреч
docs/reading-log.md  журнал чтения статей
data/                не попадает в репозиторий; как получить данные, написано ниже
results/             таблицы и рисунки, экспортированные из кода
.github/             шаблон PR, форма issue для экспериментов, CODEOWNERS, CI
```

## Проверки

`make check` запускается из трёх мест: pre-commit на вашей машине, CI на каждом PR, хук агента. Ветка `<тип>/<короткое-описание>`, заголовок PR `<тип>: ...`; типы: feat, fix, refactor, docs, test, chore, exp.
